## ✨ Overview

**Student OS** is not just an app; it's a productivity ecosystem designed for modern students. Whether you're tracking your next exam, managing your monthly budget, or keeping an eye on your residence permit expiry, Student OS puts everything you need at your fingertips with a **Pro Max** aesthetic.

## 🛡️ Key Features

### 🏛️ Bureaucracy & Residency (Specialized)
*   **Residence Permit Tracker**: Real-time monitoring of your permit status with automated expiry day calculations.
*   **Document Vault**: Secure cloud persistence for your essential student documents.
*   **Task Automator**: Integrated checklist for "Anmeldung", health insurance, and other student essentials.

### 🌤️ Intelligent Dashboard
*   **Smart Location**: Automated city detection and real-time weather integration via Weatherstack API.
*   **Quick Access Hub**: Instant navigation to Notes, Support, and System Settings.
*   **Live Greeting**: Personalized dashboard that adapts to your time of day and location.

### 📈 Academic Excellence
*   **Focus Zen**: A high-performance study timer designed to eliminate distractions.
*   **Study Analytics**: Track your weekly study targets and ECTs progress with beautiful charts.
*   **Scientific Tools**: Built-in scientific calculator and session history.

### 💰 Financial Freedom
*   **Balance Overview**: Real-time liquidity tracking for your various accounts.
*   **Job Tracker**: Manage your student job applications and working student hours.
*   **Budget Widgets**: Keep your spending in check with dedicated home screen summaries.

## 🎨 Premium Design Philsophy

Student OS follows a **Minimalist Dark Aesthetic** (Obsidian Style):
-   **Glassmorphism**: Subtle transparencies and border-refined cards.
-   **Haptic Feedback**: Meaningful physical response for every interaction.
-   **Outfit & Inter Typography**: A sophisticated blend of fonts for high readability and premium feel.
-   **Dynamic Themes**: Seamless transition between Obsidian Dark and Clean Light modes.

## 🛠️ Tech Stack

-   **Frontend**: Flutter (v3.x)
-   **State Management**: `provider` (Clean architecture)
-   **Backend**: Firebase (Auth & Firestore)
-   **Animations**: `flutter_animate` for the fluid motion.
-   **Persistence**: Secure cloud sync + local caching.
-   **APIs**: Weatherstack (Weather data), Geolocator (Positioning).

## 🚀 Getting Started

### Prerequisites
-   Flutter SDK installed
-   A Firebase project configured for Android/iOS

### Configuration
1.  Clone the repo:
    ```bash
    git clone https://github.com/yourusername/student_life_manager.git
    ```
2.  Create a `.env` file in the root directory:
    ```env
    WEATHER_API_KEY=your_weatherstack_key_here
    ```
3.  Install dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the application:
    ```bash
    flutter run
    ```
